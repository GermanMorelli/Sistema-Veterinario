Este es un proyecto para Diseño de Software sobre un programa de agendas veterinarias como caso de uso principal.

MODO DE TRABAJO:

Cada quien tiene una rama con su nombre.

1.- Hacer switch a la rama
2.- Hacer un pull de main
3.- Generar sus cambios
4.- Pushear sus cambios a su rama
5.- Desde GitHub hacer pull request (verificar que se pueda mergear)
6.- Avisarle a cualquier persona disponible que se abrió una PR
